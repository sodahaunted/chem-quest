### Project overview

   A simple website built to help students learn high school chemistry. Provides study guides and practice quizzes. Good science/STEM study notes are hard to find on the internet, especially with the rise of AI-generated websites, which makes it difficult for students to find notes that match their curriculum. chem-quest is intended to be an all-in-one study resource with original study guides and a hub for other chemistry-related study material.

It is currently a static webpage, but has more updates planned in the future.
